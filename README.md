# GitHub

# GitHub Web

## [📘 ¿Qué es GitHub?](que_es_github.md)
**GitHub** es una plataforma basada en la nube que permite a desarrolladores **almacenar, gestionar y colaborar en proyectos de software** utilizando el sistema de control de versiones Git.

## [🚀 ¿Qué es GitHub Codespaces?](codespaces.md)
Un entorno de desarrollo completo en la nube, integrado a GitHub. Funciona desde el navegador o Visual Studio Code sin necesidad de instalar nada localmente.

## [📘 Git vs GitHub](git-vs-github.md)
Antes de usar GitHub correctamente, es fundamental entender que **Git y GitHub no son lo mismo**, aunque trabajan juntos.
